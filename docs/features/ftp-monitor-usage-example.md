# FTP 自动监控功能使用示例

## 快速开始示例

### 示例 1: 基础自动监控和上传

```typescript
// 用户操作流程
1. 打开设备日志页面
2. 查看监控控制面板
3. 保持默认配置：
   - 检查间隔: 30秒
   - 自动上传: 开启
4. 点击 "启动监控" 按钮
5. 看到提示: "自动监控已启动，每 30 秒检查一次"
6. 状态显示: "监控中" 标签
```

**效果**：系统每 30 秒检查一次 FTP 服务器，发现新文件自动上传

---

### 示例 2: 高频监控场景

```typescript
// 适用场景：测试环境，需要快速响应新文件
1. 打开设备日志页面
2. 在监控控制面板中：
   - 将检查间隔设置为 10 秒
   - 保持自动上传开启
3. 点击 "启动监控"
4. 观察控制台日志：
   [AutoMonitor] 启动自动监控，间隔: 10 秒
   [AutoMonitor] 执行定时检查...
   [AutoMonitor] 发现 0 个新文件
```

**效果**：每 10 秒检查一次，快速响应新文件

---

### 示例 3: 只监控不上传

```typescript
// 适用场景：想先查看有哪些新文件，手动决定是否上传
1. 打开设备日志页面
2. 在监控控制面板中：
   - 检查间隔: 30秒
   - 关闭 "自动上传" 开关
3. 点击 "启动监控"
```

**效果**：
- 检测到新文件时，只在界面上显示
- 在控制台输出：`[AutoMonitor] 发现 2 个新文件: ["log1.tgz", "log2.tgz"]`
- 不会自动上传，可以手动选择需要的文件进行上传

## 常见使用场景

### 场景 1: 设备测试日志收集
**需求**：设备在进行长时间测试，每小时生成一个日志文件

**配置**：
- 检查间隔: 60秒
- 自动上传: 开启

**优势**：无需人工介入，自动收集所有测试日志

---

### 场景 2: 故障日志快速分析
**需求**：设备出现故障，需要立即获取日志进行分析

**配置**：
- 检查间隔: 10秒
- 自动上传: 开启

**优势**：故障发生后，日志在 10 秒内自动上传到分析服务器

---

### 场景 3: 日志审核后上传
**需求**：需要先查看日志文件名，确认后再上传

**配置**：
- 检查间隔: 30秒
- 自动上传: 关闭

**操作**：
1. 监控检测到新文件
2. 在文件列表中查看新文件
3. 手动选择需要的文件
4. 点击单独的上传按钮

## 最佳实践

### 1. 监控间隔设置建议

| 场景 | 建议间隔 | 说明 |
|------|---------|------|
| 实时监控 | 10-15秒 | 适合测试环境 |
| 常规监控 | 30-60秒 | 平衡性能和响应速度 |
| 低频检查 | 120-300秒 | 适合稳定运行的生产环境 |

### 2. 自动上传开关使用建议

| 场景 | 建议设置 | 说明 |
|------|---------|------|
| 自动化测试 | 开启 | 完全无人值守 |
| 生产环境 | 开启 | 及时收集问题日志 |
| 开发调试 | 关闭 | 手动筛选需要的日志 |

### 3. 监控前检查清单

- [ ] 确认 FTP 服务器可访问
- [ ] 确认日志服务器可访问
- [ ] 确认有足够的磁盘空间（用于临时存储下载的文件）
- [ ] 确认网络连接稳定
- [ ] 设置合适的监控间隔
