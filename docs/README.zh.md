# 🚀 Raven - 智能化 AI 生产力平台

Raven 是一个全面、多模态的 AI 生产力平台。它最初为卫星通信领域设计，现已全面进化为一个通用的跨平台 AI 客户端软件。通过整合先进的自然语言处理、强大的知识库管理（RAG）、内置的 AI 辅助终端（Chaterm）以及模型上下文协议（MCP），Raven 能够作为您所有智能工作流的中央枢纽。

## 🎯 平台架构

Raven 生态系统包含两个核心组件：
- **RavenClient**：一个功能强大的桌面应用程序（支持 Windows、macOS、Linux），基于 Electron 和 React 构建。它是您日常与 AI 交互、管理知识和运行终端会话的主要工作台。
- **RavenAIService**：强大的云端后端服务（基于 Python/FastAPI 构建），负责处理云端同步、集中的模型管理、企业级 RAG 知识处理以及共享的 MCP 服务。

## 🌟 核心特性

### 1. 💬 终极 AI 对话体验
- **多模型服务商支持**：无缝接入 OpenAI、Anthropic (Claude)、Google Gemini、DeepSeek、Ollama 以及各大开源和闭源大模型。
- **自定义 AI 智能体**：创建、管理和交互符合您工作流的专属 AI 角色（Agent）。
- **多模态能力**：在统一的对话界面中处理文本、图片、Office 文档和 PDF。

### 2. 📚 高级知识管理与 RAG
- **本地与云端向量搜索**：利用您的文档构建强大的知识库。
- **多格式解析与 OCR**：智能文档解析，支持扫描版 PDF 和图片的 OCR 识别。
- **会话无缝集成**：在与 AI 对话时，系统会自动从您的知识库中检索并引用相关上下文。

### 3. 💻 AI 驱动的集成终端 (Chaterm)
- **内嵌 SSH 终端**：通过集成的 Chaterm，直接在 Raven 中管理您的远程服务器。
- **智能命令辅助**：在终端界面中直接要求 AI 生成、解释或调试复杂的 Shell 命令。
- **统一的 LLM 桥接**：Chaterm 直接复用 Raven 核心的 AI 服务配置，确保 API 密钥的安全和统一管理。

### 4. ⚙️ 模型上下文协议 (MCP) 生态
- **可扩展的工具链**：通过 MCP 将 Raven 连接到外部系统、数据库和第三方 API。
- **服务注册与管理**：通过集中的注册表管理本地和远程的 MCP 服务器。

### 5. 🔄 云端同步与后端集成
- **RavenAIService 集成**：在多台设备之间同步您的对话历史、提示词和客户端设置。
- **团队集中管理**：非常适合需要统一管理 AI 额度、共享知识库和 API 配置的团队。

## 🛠️ 技术栈

**客户端 (RavenClient)**
- Electron + React + TypeScript
- Redux Toolkit 状态管理
- SQLite / 浏览器本地存储

**服务端 (RavenAIService)**
- Python + FastAPI
- PostgreSQL + pgvector 向量存储
- Redis + Celery 异步任务处理

## 🚀 快速开始

### 开发环境

**环境要求：**
- Node.js v22.x.x 或更高版本
- Yarn 4.9.1 (设置命令：`corepack enable && corepack prepare yarn@4.9.1 --activate`)

**安装与运行：**
```bash
yarn install
yarn dev
```

### 构建与打包
- Windows: `yarn build:win`
- macOS: `yarn build:mac`
- Linux: `yarn build:linux`
